# GMM Tab

Made to stardance hack club, to test my coding and design abilities.

## Features

* Draggable Window: Click and drag the calculator and the NASA media player to reposition them on your screen (also for touch).
* NASA Space Media (APOD): Real-time data from NASA. It automatically detects if the daily feature is an image, a native video, or a YouTube embed and renders the correct player.
* Calculator: Supports both on-screen button clicks and physical keyboard inputs (including Enter for = and Backspace for deleting).

## External:
* NASA API (APOD), daily astronomical data stream.
* Google to the search input form.
